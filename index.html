BossCat Uploader

BossCat Uploader is a private tool used by one creator to manage their own YouTube channels: BossCat-HQ and Mona Off The Frame.

It uses the YouTube Data API and the YouTube Analytics API to upload the creator's own animated videos, schedule them, set titles and descriptions, reply to comments on the creator's channels, and read the channels' own performance statistics.

The tool is not offered to the public and does not access any other person's account.
